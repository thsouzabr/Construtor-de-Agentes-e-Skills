# Contrato de integração com o Painel

O Painel do Time Inteligente é a fonte da verdade de fatos empresariais **vivos** de cada cliente.

## Regras
1. Consultar dados de cliente por interface autorizada e catálogo vigente. O nome de uma função em exemplo não prova que ela existe.
2. Nunca gravar credenciais, identificadores sensíveis, tokens, dados particulares de clientes, preços ou promessas em uma skill compartilhada.
3. Separar descrição da tarefa de dado empresarial confirmado.
4. Verificar autorização no servidor; a permissão descrita na SOUL não a concede.
5. Se falta dado obrigatório no Painel, usar **FALTA NO PAINEL**. Se a consulta homologada falhou ou não há permissão, usar **BLOQUEADO**.
6. Ausência de briefing ou de aprovação arquitetural é pendência própria, não deve ser rotulada indevidamente como falha do Painel.
7. Documentar origem, momento da consulta, versão e limitações de cada informação necessária à entrega.

**Não publicar neste repositório:** URLs privadas, segredo de integração, dados operacionais, credenciais ou cópias do catálogo interno que exponham permissões.
