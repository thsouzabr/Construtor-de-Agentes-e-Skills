**https://github.com/thsouzabr/Construtor-de-Agentes-e-Skills**

Este repositório é público para facilitar acesso do sócio e revisão do projeto. Ele contém apenas a skill-mestre, referências, modelos e validadores; não deve armazenar dados de clientes, segredos ou credenciais.

## Conferência antes de publicar
- [ ] Todos os arquivos de documentação estão em português.
- [ ] O README explica objetivo, estrutura, instalação e colaboração.
- [ ] SKILL.md mantém metodologia, diagnóstico, execução e critérios de qualidade.
- [ ] As referências são auditáveis e não contêm dados sensíveis.
- [ ] Os validadores foram executados e seus limites declarados.
- [ ] Não existem tokens, senhas, arquivos .env ou identificadores privados.
- [ ] A equipe concordou com o regime de licenciamento.
