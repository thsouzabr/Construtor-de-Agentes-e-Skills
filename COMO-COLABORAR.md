# Como colaborar

Este projeto reúne documentação, modelos e validadores para construir agentes e skills de forma responsável. Contribuições devem ser propostas por alterações pequenas, rastreáveis e revisáveis.

## Fluxo recomendado
1. Descreva o problema ou a competência em uma issue.
2. Identifique qual SOUL, skill, referência, contrato ou validador será afetado.
3. Abra uma branch de trabalho com nome descritivo.
4. Faça a alteração mantendo a documentação em português.
5. Execute os validadores locais, documentando limitações.
6. Abra um Pull Request contendo objetivo, alterações, riscos e resultados de testes.
7. Solicite revisão antes de incorporar mudanças arquiteturais.

## Critérios de revisão
- Responsabilidades e competências alinhadas.
- Metodologias específicas com fontes verificáveis.
- Ausência de dados de clientes, chaves ou credenciais.
- Contratos compatíveis, com dupla validação quando necessário.
- Testes não apresentados como executados quando somente preparados.
- Links relativos e referências internas funcionais.

## Uso compartilhado
Por enquanto, a disponibilização pública facilita leitura e colaboração com os responsáveis pelo projeto. Não foi concedida automaticamente uma licença ampla de redistribuição ou exploração comercial. Definam conjuntamente uma licença antes de abrir contribuições externas em escala.
